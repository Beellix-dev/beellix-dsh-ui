# Changelog

## 0.1.1 — initial public release candidate

- Independent native-client GUI identity and Bundle entry.
- Unified visual settings, provider connections and model discovery.
- Theme controls, three original builtin skins and a user media library.
- Configurable sidebar navigation and native workspace integration.
- Inline plugin market switching and custom catalogs.
- Desktop pets with per-pet default and custom animations.
- Archived chats grouped by workspace, with restore and single or batch deletion.
- Responsive settings dialog, with a wider layout for archived chats.

This entry records the initial public candidate, not a completed npm publication or market admission. Native compatibility and limitations are described in README; later packaging-only checks do not replace native archive acceptance.
